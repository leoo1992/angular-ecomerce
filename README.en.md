# angular-ecomerce

An Angular CLI study starter. The current branch contains the base structure of an Angular 14 application; it is not a complete online store.

## Stack
- Angular 14
- TypeScript
- RxJS

## Run
Requires Node.js 16.10 through 18.x, as specified in `package.json`.

```bash
npm install
npm start
```

Build with `npm run build`. Editable StackBlitz project: https://stackblitz.com/edit/angular-ivy-wsw6md.
