# Angular E-commerce

A study e-commerce web application built with Angular. The repository contains an Angular application structure with components, modules, and routing.

## Stack
- Angular 14
- TypeScript
- RxJS

## Run
Requires Node.js 16.10 through 18.x, as specified in `package.json`.

```bash
npm install
npm start
```

Build with `npm run build`. StackBlitz editor: https://stackblitz.com/edit/angular-ivy-wsw6md.
